# Archive

This directory contains the previous Google Apps Script + CLI implementation,
preserved for reference. The active codebase is in `web/`.

- `apps-script/` — Google Apps Script production code (Code.gs, HTML/CSS)
- `cli/` — Node.js CLI that mirrored Apps Script business logic
- `tests/` — Jest tests for the CLI engine
- `data/` — JSON data store used by the CLI (not tracked in git)

These files are no longer actively maintained. See the root CLAUDE.md for
current architecture documentation.
